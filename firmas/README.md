# Assets de firmas MCR

Imágenes públicas para las firmas de correo de MCR Agency. Se sirven por jsDelivr para que Gmail las cargue:

```
https://cdn.jsdelivr.net/gh/heartmenderocodes/MCR-AGENCY@<commit>/firmas/assets/<archivo>
```

- `logo-mcr-agency-blanco.png`: logo horizontal del tema mcr-agency.com, en blanco para la barra negra de la firma (2x).
- `sello-organizacion-comprometida-2026.png`: sello Organización comprometida 2026 (Sant Joan de Déu Solidaridad).
- `sjd-solidaridad-orden-hospitalaria.png`: logos de San Juan de Dios Solidaridad y Orden Hospitalaria, tomados de [solidaritat.santjoandedeu.org](https://solidaritat.santjoandedeu.org/) (2x).
- `iconos/`: teléfono, correo y web de [Lucide](https://lucide.dev) (ISC); Instagram y LinkedIn de [Font Awesome Free](https://fontawesome.com/license/free) (CC BY 4.0). Contacto en morado MCR `#6700F2`; redes en blanco para la barra negra. 2x.
- `rubricas/herr-von-muellerhoff/`: rúbrica de cada persona del equipo con Herr Von Muellerhoff (SIL OFL, Google Fonts), 2x. El nombre del archivo es el nombre sin acentos, en minúsculas y con guiones.
