# Assets de firmas MCR

Imágenes públicas para las firmas de correo de MCR Agency. Se sirven por jsDelivr para que Gmail las cargue:

```
https://cdn.jsdelivr.net/gh/heartmenderocodes/MCR-AGENCY@<commit>/firmas/assets/<archivo>
```

- `logo-mcr-agency-negro.png`: logo horizontal del tema mcr-agency.com, en negro para fondo blanco (2x).
- `sello-organizacion-comprometida-2026.png`: sello Organización comprometida 2026 (Sant Joan de Déu Solidaridad).
- `iconos/`: teléfono, correo y web de [Lucide](https://lucide.dev) (ISC); Instagram y LinkedIn de [Font Awesome Free](https://fontawesome.com/license/free) (CC BY 4.0). En morado MCR `#6700F2`, 2x.
- `rubricas/`: rúbrica de cada persona del equipo con Herr Von Muellerhoff (SIL OFL), 2x. El nombre del archivo es el nombre sin acentos, en minúsculas y con guiones.
